# Chemtoons website project plan

## First-release goal

Create a polished, mobile-friendly, one-page website that introduces Chemtoons and helps visitors discover its physical card game and classroom worksheets.

## Audience and actions

- Primary audience: people interested in the Chemtoons card game or worksheets.
- Primary actions: learn about the card game and visit the existing worksheet store.
- Card game action at launch: clearly labeled **Coming soon** until a real purchase destination exists.
- Worksheet action at launch: link to the existing Teachers Pay Teachers listing.

## Page structure

1. Hero and primary card-game action
2. Card game and worksheet product choices
3. Interactive Chemtoons periodic table
4. The origin story of Suzy Lee and Barry McNamara
5. Closing call to action and footer with LinkedIn contacts

## Visual direction

Chemtoons should feel like an even blend of a family game brand and an educational science brand: playful, colorful, modern, approachable, and credible without feeling childish or academic.

The featured character group is Carbon, Helium, Oxygen, Nitrogen, and Sulfur. The visual identity will include a code-based wordmark, a flexible color system, friendly modern typography, and chemistry-inspired details.

## Interactive periodic table

- Preserve the recognizable periodic-table layout on large screens.
- Preserve that layout in a clearly scrollable region on small screens.
- Show an optimized character thumbnail in each available tile.
- Open an accessible detail view with the element name, symbol, atomic number, family, atomic weight, artwork, and card-game fact.
- Do not call attention to characters that have not yet been illustrated.
- Support mouse, touch, and keyboard interaction.

## Founders' story

Suzy Lee created the element characters after chemistry became her favorite high-school subject. She later moved from chemistry into computer science while keeping a passion for approachable science communication.

Suzy and Barry McNamara met while working on a Google project coincidentally named “Elements.” Barry's love of games later inspired them to turn Suzy's characters into a card game while planning their wedding favors.

Chemtoons is not intended to make someone a chemistry expert. Its purpose is to make a first encounter with chemistry feel fun, welcoming, and unintimidating.

## Delivery milestones

1. Prepare the development computer.
2. Create and document the React, TypeScript, and Vite foundation.
3. Develop the Chemtoons visual identity and page structure.
4. Add the product and founder-story content.
5. Build the interactive periodic table.
6. Verify accessibility, performance, responsive behavior, and production output.
7. Publish `codethecoffee/chemtoons` with GitHub Pages, then connect `chemtoons.com` after review.

Each milestone should use focused commits with descriptive messages.
